# Vitae Stack 0.1.0

This document is the planned release note for an unpublished release. It does not claim that a public artifact exists.

## Included

- Local-only, no-account Windows x64 portable package with bundled Node.js.
- One automatically provisioned private workspace stored in local SQLite plus a local files folder.
- Structured career information, evidence approval, immutable facts, document versions, job analysis, evidence matching, grounded resume/cover-letter tailoring, manual editing, deterministic ATS estimates, and PDF/DOCX/Markdown/text/JSON exports.
- Optional Ollama and OpenAI-compatible provider configuration; no hosted AI service is required.
- Versioned portability export/import and explicit managed-data deletion.

## Start

Extract `vitae-stack-personal-0.1.0-windows-x64.zip` and double-click `Start Vitae Stack.cmd`. No account, Docker, PostgreSQL, Node installation, or environment editing is required. Data defaults to `%LOCALAPPDATA%\Vitae Stack`; stopping the app preserves it.

## Limits

The release is single-user and loopback-only. Remote hosting, multiple accounts, shared workspaces, OCR, job-board scraping, application submission, native mobile apps, and proprietary ATS reproduction are unsupported. ATS results are estimates. AI quality depends on the model the user selects, and unsupported factual claims cannot enter final export.

## Upgrade and recovery

Stop the app and copy the complete data folder before upgrading. Application binaries are separate from data. Restore a full coordinated data-folder copy rather than mixing individual database or artifact files. See [backup and restore](../operations/BACKUP_AND_RESTORE.md).
