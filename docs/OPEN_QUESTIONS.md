# Open questions

There are no unresolved decisions blocking the local-only MVP.

Post-MVP ideas such as remote identity, multi-user hosting, additional locales, OCR, or native desktop shells are not implementation questions for this release and must not expand its scope. Introducing remote access would require a new product decision, threat model, and ADR; it must not be enabled by configuration alone.

Resolved implementation decisions are summarized in [architecture decisions](architecture/DECISION_SUMMARY.md) and [ADR-0021](adr/0021-local-sqlite-no-account-runtime.md).
