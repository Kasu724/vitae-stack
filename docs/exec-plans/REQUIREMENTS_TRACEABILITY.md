# Requirements Traceability

Public traceability records should connect user-visible behavior, tests, and release evidence without exposing private planning notes.

## Current Scope

- Local-only, single-user operation.
- No account required for the personal package.
- User-controlled local data storage, backup, restore, export, and deletion.
- Evidence-grounded generated career content.
- Explainable ATS estimate rather than hiring-outcome prediction.
- Safe file ingestion and bounded document export.
- Optional model providers behind explicit user configuration.

## Evidence Expectations

Every behavior change should identify the affected workflow, the test coverage added or updated, and any release or migration note needed by users.
