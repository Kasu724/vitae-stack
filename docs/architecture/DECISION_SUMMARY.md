# Foundation decision summary

|   # | Decision                                                                                                                                                                                                                               |
| --: | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
|   1 | MVP is local-only, single-user, no-account, and loopback-bound. [ADR-0021](../adr/0021-local-sqlite-no-account-runtime.md)                                                                                                             |
|   2 | Structured data lives in one local SQLite file; uploaded/generated bytes live in a sibling local folder.                                                                                                                               |
|   3 | The Windows x64 ZIP bundles Node.js and requires no installer, container runtime, database server, or proprietary service. [Deployment](DEPLOYMENT.md)                                                                                 |
|   4 | Provider credentials are optional, write-only after entry, and locally encrypted with a generated key. [Secrets](../security/SECRET_MANAGEMENT.md)                                                                                     |
|   5 | Provider paths are generic OpenAI-compatible endpoints and Ollama; no hosted model is required. [Providers](../ai/MODEL_PROVIDER_SUPPORT.md)                                                                                           |
|   6 | Structured model outputs use closed schemas, semantic/provenance validation, and at most two bounded repair attempts. [Schemas](../ai/STRUCTURED_OUTPUT_SCHEMAS.md)                                                                    |
|   7 | Approved facts are immutable; corrections supersede; withdrawal excludes future use; deletion previews dependents. [Career model](../adr/0007-structured-career-model.md)                                                              |
|   8 | Document versions snapshot claims/evidence; changed factual spans become unverified and block final export until grounded. [Provenance](PROVENANCE_MODEL.md)                                                                           |
|   9 | ATS analysis is produced by assigned AI-11 models, may include an optional reviewed job source, records immutable model provenance, and never controls grounding or export eligibility. [ATS ADR](../adr/0023-ai-only-ats-analysis.md) |
|  10 | PDF/DOCX input and output use bounded parsers/renderers with no macros, scripts, remote resources, or executable templates. [Pipeline](DOCUMENT_PIPELINE.md)                                                                           |
|  11 | Job URL retrieval permits public HTTPS only and revalidates DNS and every redirect with strict limits. [SSRF ADR](../adr/0017-ssrf-safe-url-fetching.md)                                                                               |
|  12 | Portability export is versioned and excludes secret plaintext; deletion removes managed local data but cannot remove user-created copies. [Retention](../security/DATA_RETENTION_AND_DELETION.md)                                      |
|  13 | Remote hosting, accounts, collaboration, scraping/submission, OCR, proprietary ATS emulation, training on user data, executable templates, and microservices are excluded. [Non-goals](../product/NON_GOALS.md)                        |
|  14 | Release readiness requires AC-001 through AC-027, M01 through M22, all quality gates, and a clean portable-package launch/restart/persistence test. [MVP scope](../product/MVP_SCOPE.md)                                               |
