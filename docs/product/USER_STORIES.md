# User stories

Stories reference product requirements and are acceptance-oriented.

- **US-01 (PR-001–003):** As a job seeker, I can build a structured career bank and approve facts so generation uses only information I recognize as true.
- **US-02 (PR-006–007):** As a user with existing documents, I can import them and review source-linked extraction proposals before they affect my profile.
- **US-03 (PR-008–010):** As an applicant, I can paste, upload, or safely retrieve a job and correct its extracted requirements.
- **US-04 (PR-011):** As a career changer, I can see which requirements have strong, weak, conflicting, or no evidence and adjust the selected evidence.
- **US-05 (PR-012–018):** As an applicant, I can lock content, receive atomic grounded suggestions, inspect evidence and rationale, and accept only changes I choose.
- **US-06 (PR-016):** As a user, I can save an unverified manual draft but cannot accidentally label unsupported factual text as final.
- **US-07 (PR-019):** As an applicant, I can understand estimated ATS risks by category and rule without being told a hiring probability.
- **US-08 (PR-004–005):** As a user, I can compare and restore document versions without destroying history.
- **US-09 (PR-020):** As a user, I can export accessible, readable documents and understand why an export is blocked.
- **US-10 (PR-021, PR-025):** As a data owner, I can export everything or permanently delete it with a clear dependency preview and status receipt.
- **US-11 (PR-022, PR-024):** As a privacy-conscious user, I can choose a local or remote model and see exactly where selected content will go.
- **US-12 (PR-023, PR-026):** As an operator, I can deploy without proprietary infrastructure and prevent users from accessing one another's data.
- **US-13 (PR-027):** As a disabled user, I can complete every core flow without pointer-only interaction or loss at zoom/reflow.
- **US-14 (PR-029):** As a user, I can retry or resume failed work without duplicate documents, claims, or charges caused by the application.
