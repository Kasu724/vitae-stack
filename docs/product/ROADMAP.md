# Roadmap

## Phase 0 — Foundation

Milestones M01–M03 establish reproducible tooling, PostgreSQL/migrations, authentication modes, workspace isolation, and security test harnesses. Private artifact handling arrives in M06. No AI workflow should precede the foundation and identity controls.

## Phase 1 — Verified career data

M04–M07 deliver the CIB, document/version primitives, safe import, and approval. The phase exits when no unapproved extraction can enter generation context.

## Phase 2 — Job evidence and providers

M08–M12 deliver text/file and secure-URL ingestion, reviewed requirements, evidence matching, and capability-negotiated provider adapters. This is the first useful analysis-only release candidate.

## Phase 3 — Grounded documents

M13–M18 deliver grounded resume/letter tailoring, editor suggestion review, ATS estimates, export, settings, portability, and deletion. This is feature-complete MVP, not release-ready.

## Phase 4 — Release hardening

M19–M22 complete abuse testing, WCAG/responsive validation, end-to-end/recovery checks, and signed self-hosted release artifacts.

## After MVP

External OIDC, shared workspaces, OCR, multilingual parsing/ATS rules, semantic retrieval, additional provider adapters, accessible template extensions, and operator scaling. Experimental work requires opt-in flags, evaluation evidence, and no bypass of grounding or security gates.

The milestone graph and parallel lanes are authoritative in [MVP implementation](../exec-plans/active/MVP_IMPLEMENTATION.md).
