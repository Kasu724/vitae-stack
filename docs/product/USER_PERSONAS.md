# User personas

## P1 — Evidence-conscious job seeker

Maintains several resume variants and wants every factual claim tied to approved career evidence. Needs clear source review, unsupported-claim blocking, versions, editable suggestions, and dependable exports.

## P2 — Career changer or early-career user

Has useful projects, coursework, volunteering, research, and accomplishments that may not appear on an existing resume. Needs guided structured entry, gap visibility, and no invented experience.

## P3 — Privacy-first local-model user

Does not want an application account or cloud data store. Needs a download-and-run local tool, visible provider destinations, optional Ollama support, complete portability/deletion, and useful manual/deterministic workflows without AI.

## P4 — Nontechnical personal user

Wants to extract a ZIP, double-click Start, and know where data is stored. Does not administer databases, containers, authentication, networks, or server secrets. Needs clear stop, backup, restore, upgrade, and deletion instructions.

Recruiters, employers, shared teams, hosted-service operators, and automated job applicants are not MVP personas.
