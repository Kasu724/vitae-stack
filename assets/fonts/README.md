# Export font

`NotoSans-Regular.ttf` is the full, hinted static Noto Sans 2.015 regular face, bundled solely for deterministic Unicode PDF export. It was extracted from the upstream [`NotoSans-v2.015`](https://github.com/notofonts/latin-greek-cyrillic/releases/tag/NotoSans-v2.015) release archive at `NotoSans/full/ttf/NotoSans-Regular.ttf`.

- Distributed file SHA-256: `f5f552c8c5edb61fe6efb824baf4d4de47b1a8689ab4925ff43f7bd6a4ebece5`
- License: SIL Open Font License 1.1; see `OFL.txt` in this directory.

The static face contains 4,515 glyphs covering 3,094 Unicode code points. The renderer embeds a document-specific subset. It does not fetch fonts or other resources while rendering.
